# Бизнес-калькулятор

Оценка и планирование проекта для ИП в России: налоговые режимы 2026 года, финансовая модель по месяцам, SWOT/PESTEL со сценариями.

**Это инструмент оценки, а не налоговая консультация.** Параметры сверены с НК РФ ч. 2 в ред. с 01.10.2026, 422-ФЗ (ред. 04.08.2026), 17-ФЗ (ред. 28.11.2025); статус каждого параметра — на экране «Параметры».

## Что внутри

| Модуль | Файл | Что делает |
| --- | --- | --- |
| M0 · Параметры | `src/params.template.html` | справочник ставок и лимитов по годам, правки с комментарием |
| Налоговый движок | `src/engine.js` | НПД, ПСН, УСН 6/15, АУСН 8/20, ОСНО для ИП; НДС на УСН 5/7/22% |
| Финмодель | `src/finmodel.js` | помесячно: БДР, БДДС, NPV, IRR, окупаемость, точка безубыточности, чувствительность |
| Анализ | `src/analysis.js` | SWOT, PESTEL, TOWS, сценарии (пессимистичный / ожидаемый / базовый / оптимистичный) |
| Проекты | `src/storage.js` | формат проекта, проверка при импорте, миграции, хранилище |
| Справочник | `src/glossary.js` | 40+ показателей: смысл, формула, как читать, оговорки |
| Интерфейс | `src/app.js`, `app.css`, `app.body.html` | экраны приложения; `scripts/build.py` собирает всё в `www/` |

## Сборка

```bash
npm install
npm test                 # 4 набора тестов на ручных примерах
python3 scripts/build.py # собирает www/index.html и www/params.html из src/
npx cap add android      # один раз
npx cap sync android
```

APK собирается в облаке: **Actions → Android APK** → артефакт `biz-calc-debug-apk` (запускается при каждом push в `main` или вручную).

## Установка на телефон

1. Открыть последний успешный запуск в Actions, скачать `biz-calc-debug-apk` (zip), распаковать.
2. Перенести `app-debug.apk` на телефон и открыть. Android попросит разрешить установку из этого источника.
3. Это отладочная сборка (debug-подпись): для себя — нормально, для Google Play нужна release-подпись.

## Допущения v0.6

Только ИП; проект стартует в январе; кассовый метод; налоги считаются за календарный год и платятся по срокам (см. экран модели). Не учтены: ООО, совмещение режимов, торговый сбор. Полный список — внизу экрана модели.

## Подпись

`signing/debug.keystore` — постоянный отладочный ключ (пароль `android`), чтобы новые APK ставились поверх старых без удаления. Для публикации в магазинах нужен отдельный release-ключ, который в репозиторий не кладут.
